# LE JEU DU RN

Jeu de l'oie satirique jouable dans un navigateur, jusqu'à 6 joueurs.

## Jouer en local
Téléchargez `index.html`, puis ouvrez-le dans un navigateur récent (Chrome, Firefox, Edge ou Safari).

## Publier gratuitement avec GitHub Pages
1. Créez un compte sur https://github.com si vous n'en avez pas.
2. Cliquez sur **New repository**.
3. Nommez le dépôt `le-jeu-du-rn` et choisissez **Public**.
4. Dans le dépôt, faites **Add file → Upload files**.
5. Déposez `index.html` à la racine du dépôt, puis cliquez sur **Commit changes**.
6. Ouvrez **Settings → Pages**.
7. Dans **Build and deployment**, choisissez **Deploy from a branch**.
8. Choisissez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
9. Après quelques minutes, GitHub affichera l'adresse publique du jeu dans la section **Pages**. Elle aura généralement cette forme :
   `https://VOTRE-PSEUDO.github.io/le-jeu-du-rn/`

## À savoir
- Le jeu charge la bibliothèque 3D Three.js depuis un CDN : une connexion Internet est donc nécessaire pour afficher le plateau 3D.
- Le fichier contient le jeu dans une seule page HTML ; aucun serveur personnel n'est nécessaire.
- Vérifiez les règles, les questions, les illustrations et les éventuels droits d'utilisation avant une diffusion publique.
- Aucun nom, logo ou visuel officiel ne doit laisser croire à une affiliation avec un parti ou une institution.

## Mise à jour
Pour publier une nouvelle version, remplacez `index.html` dans le dépôt par le nouveau fichier, puis validez les changements.
